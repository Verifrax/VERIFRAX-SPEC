# Contributing

This repository is a derived specification publication surface.

## Repository boundary

- VERIFRAX authors the active normative source material.
- VERIFRAX-SPEC publishes derived specification artifacts from VERIFRAX.
- This repository is not the upstream repository authority surface.

## Contribution rules

- PRs only (no direct pushes to main)
- keep published specification material aligned with `Verifrax/VERIFRAX`
- do not introduce wording that makes this repository the authored source boundary
- do not introduce wording that makes derived publication artifacts upstream authority
