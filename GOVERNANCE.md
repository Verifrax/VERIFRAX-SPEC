# GOVERNANCE

This repository publishes derived governance and specification material from VERIFRAX-authored source material.

This repository is a derived publication surface.

This repository is not the upstream repository authority surface.

- VERIFRAX authors normative source material.
- VERIFRAX-SPEC publishes derived specification artifacts from VERIFRAX.
- Derived specification artifacts are not upstream repository authority.
- Governance authority is external and bound through AUCTORISEAL plus the governed repo set in `.github`.

This document describes governance interpretation for this derived publication surface.

## Repository governance boundary

This repository may publish governance-related material derived from VERIFRAX-authored source material.

It does not originate upstream repository authority.

It does not redefine authority outside the governed authority boundary bound through AUCTORISEAL and `.github`.

## Integrity rule

Changes in this repository must remain aligned with the source material authored in `Verifrax/VERIFRAX`.

Derived publication updates must not introduce upstream authority claims, dual-source ambiguity, or contradictory governance wording.

## Publication rule

Published governance material in this repository is informational and derived unless an external governed authority record explicitly states otherwise.

Absent an explicit external governed authority record, this repository remains downstream of VERIFRAX-authored source material.
